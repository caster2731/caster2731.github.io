Kenmo FM

KenmoFMは、最新のAI技術とインターネット文化を融合させた、24時間365日稼働の自動ラジオ放送システムです。
5ちゃんねる（嫌儲板）の熱気あるスレッドから、古今の名作文学、そしてAIによる鋭いニュース解説まで、多彩なコンテンツを全自動でキュレーション・生成し、リスナーに届けます。

Concept

「インターネットの喧騒を、心地よいラジオへ」
KenmoFMは、テキストベースのインターネット上の議論や情報を、聴覚的なエンターテインメントへと昇華させます。
Google Cloud TTS、Voicevox、Bert-VITS2などの高度な音声合成技術を駆使し、単なる読み上げを超えた「ラジオ番組」としての体験を提供します。

Key Features

  • 全自動スレッド読み上げ & ラジオ化
    5ちゃんねる（嫌儲板）の勢いのあるスレッドをリアルタイムで取得。高性能フィルタリングと、時間帯に合わせたBGM/SE演出でプロのラジオのような聞き心地を実現。
    定時の時報やジングル、そして「嫌儲十訓」の定期放送も。
  • AIニュース解説・コメンタリー
    Gemini API / NotebookLMを活用し、最新ニュースをAIが独自の視点で解説。AI Duoモードによるキャラクター同時の掛け合いで、深みのある議論を展開します。
  • 多彩な専門コーナー
    深夜の「怪談コーナー」、情感豊かな「文学コーナー」、そしてAI DJが盛り上げる音楽放送「Musicthon」。
  • ポッドキャスト自動配信
    放送されたコンテンツの一部は自動的にパッケージ化され、Apple PodcastsやSpotifyへ配信されます。

Technical Highlights

  • Multi-TTS Engine: Google Cloud TTS (Chirp3, Neural2), Voicevox, Bert-VITS2 (実験的モデル)
  • Automated Mixing: FFmpegとPygameを駆使したリアルタイムかつ高品質な音声ミキシング
  • Expandability: 新しいコーナーを柔軟に追加できるプラグイン的アーキテクチャ

Vision

インターネットの「今」を切り取り、AIの力で再構築する。
KenmoFMは、作業用BGMとして、あるいは情報収集ツールとして、リスナーの生活に寄り添う新しいメディアの形を提案します。

Key Features

    リアルタイムで「tail -f」のように監視

Additional Features

  • 🇯🇵 日本語対応: 日英切り替え可能
  • 📂 ファイルブラウザ: GUIでログファイル選択

Gravity Storage 🪐

Key Features

  • 惑星メタファー

  • サイズと重力

  • 3D探索
    マウス操作で回転・ズーム、フォルダクリックでドリルダウン

技術スタック

IP Scanner v2

IP Scanner v2 は、高速で動作する非同期Webサービスクローラーおよび簡易脆弱性診断ツールです。
指定したIPアドレスやランダムなIPアドレスに対してスキャンを実行し、発見したWebサーバーの情報（タイトル、ヘッダー、SSL証明書の有効期限など）を収集し、リアルタイムでダッシュボードに表示します。

Key Features

  • 高速な非同期スキャン
    aiohttp を活用した並行処理により、高速なネットワークスキャンを実現。
  • 2つのスキャンモード
    ・指定IPスキャン (Target Scan): 特定のIPアドレス、CIDR、またはドメイン名を指定してスキャン。
    ・ランダムIPスキャン (Random Scan): インターネット上のIPアドレスをランダムに生成して探索。
  • 詳細なサービス情報収集
    ステータスコード、ページタイトル、サーバーヘッダ情報、SSL/TLS証明書情報（発行者、ドメイン、有効期限）、逆引きDNSによるホスト名解決、IPアドレスから国籍情報を取得。
  • 自動スクリーンショット機能
    Playwright を使用して、発見したWebページのスクリーンショットを自動的に撮影・保存。
  • 簡易脆弱性スクリーニング
    重大なセキュリティヘッダの欠落チェック、管理パネルや機密ファイルの露出スキャン、古いSSL証明書や自己署名証明書の検出、ディレクトリリスティング等の設定ミスチェック。
  • リアルタイム・ダッシュボード
    WebSocketを利用し、スキャン進行状況や発見されたサービスをブラウザ上のモダンなUIでリアルタイムに確認可能。

技術スタック

  • Backend: Python 3.x, FastAPI, aiohttp, SQLite (aiosqlite)
  • Frontend: HTML5, Vanilla CSS, Vanilla JavaScript, WebSocket
  • Automation: Playwright (スクリーンショット取得用)

石油備蓄枯渇タイマー ⏱

日本の石油備蓄があと何日で枯渇するか、リアルタイムでカウントダウン表示するシミュレーション型ダッシュボードです。
資源エネルギー庁の公式統計データ（254日分の備蓄）を基準に、複数のシナリオでの枯渇時期を算出。SFチックなUI演出と、原油価格・関連ニュースのリアルタイム連携が特徴です。

Key Features

  • リアルタイムカウントダウン
    1秒間隔で日・時・分・秒を刻み、石油備蓄の枯渇までの残り時間を視覚化。残り日数に応じて「ケンモくん」の表情が6段階に変化する演出付き。
  • 3つのシナリオ切り替え
    ・完全輸入停止 (drainRate: 1.0): ベースライン238日で枯渇
    ・50%輸入削減 (drainRate: 0.5): 約476日に延長
    ・節約モード (drainRate: 0.8): 消費20%減で約297日
  • WTI原油価格リアルタイム表示
    FRED API経由でWTI原油価格を取得し表示（1時間キャッシュ）。
  • 関連ニュース＆5chスレッド
    Yahoo/NHK/朝日のRSSフィードと5ch嫌儲板の石油関連スレッドを自動取得。勢いランキング算出でホットな話題を優先表示（5分キャッシュ）。
  • ソーシャルシェア
    X / LINE / Reddit へのワンクリック共有とClipboard APIによるコピー機能。280blocker回避のwindow.open方式を採用。

Technical Highlights

  • Frontend: Next.js 16 (静的エクスポート)、'use client'コンポーネント、KenmoFMとは独立したスタンドアロンレイアウト
  • Backend API: Flask (Python) — /api/oil-thread, /api/oil-price, /api/counter/timer の3エンドポイント
  • External APIs: FRED API (WTI原油価格)、5ch subject.txt (勢い計算)、RSS (Yahoo/NHK/朝日)
  • Visual Effects: CSSアニメーションによる油滴エフェクト、ネオンレッドのアクセントカラー、備蓄残量プログレスバー
  • SEO/OGP: og:image、Twitter Card (summary_large_image)、robots: index, follow
